# Kotak Private IPL Fantasy League 2026

A full auction + scoring platform for the Kotak floor mock IPL auction.

## 🚀 How to Deploy to GitHub Pages (5 minutes)

### Step 1 — Create a GitHub Account
Go to [github.com](https://github.com) and sign up (free).

### Step 2 — Create a New Repository
1. Click the **+** button → **New repository**
2. Name it: `kotak-ipl-2026`
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload Files
1. Click **uploading an existing file**
2. Drag and drop ALL files from this folder:
   - `index.html`
   - `_config.yml`
   - `data/players.js`
   - `js/auction.js`
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to your repo → **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Select **main** branch → **/ (root)**
4. Click **Save**

### Step 5 — Your site is live!
Within 2 minutes your site will be at:
`https://YOUR-GITHUB-USERNAME.github.io/kotak-ipl-2026`

Share this link with your floor! 🏏

2. Get your API key (free tier: 100 calls/day)
3. In the site → Scores tab → ⚙ API Settings → paste your key

## Features
- ⚡ Live auction room with category rotation (Batters / WK / All-Rounders / Fast / Spin)
- 🎲 Random subcategory draw (7-8 players per set)
- 🔄 RTM tracking for 6 returning teams + Wonder Women
- 💰 Real-time wallet tracking per team
- 📋 Unsold pool → Round 2
- 🏆 Leaderboard with bonus categories
- 📊 Score updates (manual + CricAPI)
- 🔐 Admin password protected updates
